# Tokens de uma direção proposta

Use JSON com `brand`, `background`, `foreground`, `accent`, `font_family` e `approval_status` (`proposed` ou `approved`). Cores são hexadecimais #RRGGBB. Não use exemplo genérico como identidade confirmada.

Associe no brief origem de cada escolha, revisão, papel das cores, hierarquia e aprovação. A revisão exibida define a aprovação; mudar arquivos depois invalida a equivalência. Se usar editorial-templates, o helper confere contraste do texto e gera SVGs editáveis. Essa verificação mecânica não substitui a inspeção visual nem a aprovação da pessoa.

Cada aplicação ocupa 1080×1350 e tem margens internas. O arquivo reutilizável pode ter outro formato de edição, desde que exporte 4:5 e preserve tokens e conteúdos separados.
