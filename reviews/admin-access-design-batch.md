# Acessos · rótulos em caixa de frase

Exportação limitada aos três arquivos de `site/admin/acessos/`, após correção
na fonte privada. Rótulos estáticos e badges dinâmicos passam a usar caixa de
frase; o CSS usa Archivo 600 a 14/21 px, sem tracking decorativo.

O Paper editável foi inspecionado em 1440, 768 e 390 px. A prévia local dos
arquivos Web não mostrou overflow horizontal nessas larguras. O servidor
estático não fornece a API de autenticação: apenas o estado indisponível foi
verificado no navegador. Pesquisa e concessão/revogação ainda exigem QA com
conta autorizada. Nenhuma imagem, fluxo de acesso ou conteúdo editorial foi
alterado. Esta entrega não declara as demais páginas padronizadas.
