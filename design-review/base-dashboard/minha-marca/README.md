# Minha marca: revisão visual

Capturas locais em Chrome, com dados fictícios de uma marca de exemplo.
Os arquivos `antes-*` mostram a entrada sem documento; os demais mostram as três
telas após importação. Cada tela foi conferida em 1440, 768 e 390 px.
O documento real enviado pelo usuário e as capturas com seu conteúdo não foram
incluídos no repositório público.
