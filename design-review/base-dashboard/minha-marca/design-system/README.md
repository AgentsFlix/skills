# Minha marca: design system e arte editorial

Capturas locais em Chrome com uma base fictícia. O conjunto registra o estado
posterior ao alinhamento com `design.md`: superfícies escuras, hierarquia de
texto, ciano apenas para orientação e seleção, raios do sistema e ilustrações
PNG transparentes no lugar dos desenhos SVG de conteúdo.

As capturas anteriores permanecem no diretório pai e em `../radius/`. Cada uma
das três telas foi conferida em 1440, 768 e 390 px. `qa.json` registra largura
real, ausência de overflow horizontal e erros de execução.
